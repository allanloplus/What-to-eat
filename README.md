# Allan在哪裡，要吃甚麼？

Allan 和 AI 小助手「阿拉蕾」的覓食分鏡。選心情、看天氣、挑飯友，阿拉蕾從台灣 22 縣市 305 道在地美食、加上 68 道全台通用美食（共 373 道）裡挑出最適合現在的一道，再用「美食雷達」找附近的店。

純前端靜態網頁，不需要後端、不需要 API 金鑰，丟上 GitHub Pages 就能用。

製作：Allan Lo，2026/10/18

## 怎麼玩

1. **地點**：按「自動定位」，或點台灣方塊地圖上的縣市（含澎湖、金門、馬祖），右邊會列出當地美食，非當季的會劃掉，📌 代表有朋友推薦的口袋名店。
2. **天氣和時段**：選好縣市後自動查即時天氣（Open-Meteo），時段依台灣時間自動判斷；都可以手動改。
3. **心情**：Allan 的九宮格表情就是選項（心情不錯、超開心、選擇障礙、想嘗鮮、忙到爆、壓力山大、心情低落、想犒賞自己、累到傻眼）。
4. **飯友**：一個人吃，或約好朋友、老同學、約會、家人、同事、客戶、長輩、小朋友（可複選），設定人數與飯友名字。
5. **偏好**：推薦範圍（全部美食／只推在地代表性美食）、預算（小資／剛好／豪華）、忌口（素食、不吃辣、不吃牛、不吃海鮮、清淡減脂）、可以走多遠。選「在地代表性美食」時只從該縣市的名產裡挑；如果那個時段沒有在地美食（例如新竹市的消夜），會改推全部美食並說明。
6. 按「🔮 開始分析」，阿拉蕾的全息分析畫面跑完就出結果。

懶得選？按首頁的「⚡ 交給阿拉蕾決定」，它會自己定位、猜你的心情，直接推薦。

## 推薦結果能做什麼

| 功能 | 說明 |
| --- | --- |
| 📌 口袋名店 | 有朋友推薦店家的菜（目前是金門 10 家），結果頁和美食雷達會直接附上 Google 地圖連結 |

## 阿拉蕾怎麼判斷

`js/engine.js` 是一個可解釋的評分引擎：

- 先篩掉不符合時段、不在這個縣市、不是當季、或違反忌口的品項。
- 再依天氣、心情、飯友組成、人數、預算、清淡偏好、節日、最近的飲食紀錄加減分，最後加一點可重現的「直覺」亂數讓結果有變化（「換一批」就是換亂數種子）。
- 有 GPS 定位時，名產所在的鄉鎮就在 8 公里內會再加分（例如人在溪湖附近，溪湖羊肉爐會往前排）；有口袋名店的菜也會小幅加分。
- 取前六名時同類型最多兩道、同一種菜只留一道，並盡量保留兩道在地美食。

在 claude.ai 的 Artifact 裡開啟時，頁面會另外請 Claude 從前六名中挑一道、用阿拉蕾的口吻說明理由（右上角會出現「✨ Claude AI」標記）。一般網址開啟時則使用內建的說明文字，不需要任何金鑰。

## 隱私設計

這個頁面處理的個人資料只有「位置」，所以照資料最小化原則設計：

- 座標只在瀏覽器記憶體裡使用，不寫入本機儲存，也沒有自家伺服器。
- 查天氣時座標四捨五入到小數 2 位（約 1 公里），查店家時到小數 3 位（約 100 公尺）才送出。
- 美食護照與偏好設定只存在這台裝置的 localStorage，護照裡可以一鍵刪除全部紀錄。
- 不定位也能用：直接點縣市即可，天氣改用縣市中心查詢。

## 在本機執行

需要透過網址開啟（直接雙擊 `index.html` 也能用，但飯局卡圖片會被瀏覽器擋下）：

```bash
npm start          # 用 http-server 在 http://localhost:8080 開啟
npm test           # 推薦引擎與資料檢查（Node 18 以上）
```

## 部署到 GitHub Pages

Repository → Settings → Pages → Source 選「Deploy from a branch」，Branch 選放這些檔案的分支、資料夾選 `/ (root)`。網址必須是 HTTPS，瀏覽器才會允許定位。

## 新增或修改美食

在 `js/data.js` 找到對應縣市的 `foods`，照格式加一行：

```js
f('牛肉湯', '🥩', 'b l d n', 'soup', 'p2 hot soup beef classic', '牛肉湯', '溫體牛現切，熱湯一沖就熟'),
//  名稱     emoji  時段        類別    標籤（價位＋特性）           搜尋關鍵字  介紹
```

時段代號：`b` 早餐、`l` 午餐、`t` 下午茶、`d` 晚餐、`n` 消夜。可用的標籤和類別寫在同一個檔案的 `TAG_LABELS`、`CAT_LABELS`。最後一個參數可以加：

```js
{
  months: [5, 6, 7],                 // 季節限定，其他月份不推薦
  town: '溪湖',                       // 名產所在鄉鎮，要先在 TOWNS 加座標
  shops: [                           // 口袋名店，會顯示在結果頁與美食雷達
    { name: '小雪花廣東粥', url: 'https://maps.app.goo.gl/…', note: '招牌菜（選填）' },
  ],
}
```

改完跑 `npm test`，會檢查格式、鄉鎮座標是否落在該縣市、名店連結格式，以及前六名不會重複同一道菜。
